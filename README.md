# מעבדת הצירים ההורמונליים

סימולטור לימודי אינטראקטיבי למדעי הבריאות (כיתה י"א): איך ציר הורמונלי עובד, איך משוב שלילי שומר על איזון, ומה קורה בהפרעות אנדוקריניות.
אפליקציה סטטית (HTML + CSS + JavaScript). בלי שרת, בלי מסד נתונים, בלי מפתחות API, בלי הרשמה.

## מה יש בגרסה הראשונה

| ציר | מצבים קליניים |
|---|---|
| בלוטת התריס | תקין · גרייבס (נוגדנים מגרים) · אדנומה רעילה / זפק רב-קשרי · אדנומה מפרישת TSH · תת-פעילות ראשונית (השימוטו) · משנית · שלישונית |
| קורטיזול | תקין · מחלת קושינג · אדנומה אדרנלית · ACTH אקטופי · גלוקוקורטיקואידים חיצוניים · אדיסון · אי-ספיקה משנית |
| הורמון גדילה | תקין · ענקות / אקרומגליה · מחסור ביותרת המוח · מחסור בהיפותלמוס (GHRH) · תסמונת לרון |

- **מצב למידה:** בוחרים מצב קליני. האנימציה מתחילה בציר התקין, מסמנת את מקור ההפרעה, ומראה שלב אחר שלב את ההשלכות, את תגובת המשוב ואת המצב הסופי.
- **מצב אבחון:** מקרה אקראי. אין שם מחלה, אין סימון מקור, אין כיתובים מסבירים. בוחרים אבחנה ושולחים. אחרי התשובה האנימציה חוזרת עם סימון המקור וההסבר.
- בקרות: הפעלה/השהיה, התחלה מחדש, שלב קודם/הבא, מעבר ישיר לשלב, מהירות 0.5×–2× (גם מקש רווח).

## הרצה מקומית

הדרך הפשוטה: לפתוח את `index.html` בדפדפן (לחיצה כפולה). האפליקציה אינה דורשת שרת.

או עם שרת מקומי (דורש Node.js):

```bash
node tools/serve.js
```

ואז לפתוח את http://localhost:8765

## פרסום ב-GitHub Pages

1. ליצור מאגר ב-GitHub ולהעלות אליו את תוכן התיקייה (`index.html`, `css/`, `js/`).
2. ב-Settings ← Pages: Source = "Deploy from a branch", הענף `main` והתיקייה `/ (root)`.
3. אחרי דקה האתר זמין ב-`https://<user>.github.io/<repo>/`.

כל הנתיבים יחסיים, ולכן האתר עובד גם בתת-נתיב. אפשר גם קישור ישיר לציר ולמצב, למשל `#cortisol/diag`.

## בדיקת איכות פיזיולוגית

```bash
node tests/validate.js
```

הסקריפט עובר על כל מחלה ובודק:

1. האנימציה מתחילה במצב תקין, ולכל מחלה יש שלב הפרעה ושלב סיום.
2. הרמות המצטברות מהשלבים שוות לרמות הסופיות (`final`) שהוגדרו.
3. **כל שלב מגרה את הבא** (למשל TSH גבוה → T3/T4 גבוהות), אלא אם המחלה מצהירה במפורש שההפרשה אוטונומית או פגועה (`forwardOverrides`).
4. **משוב:** רמה גבוהה של ההורמון המעכב מורידה את היעד, וההפך, אלא אם קשת המשוב מסומנת כחסומה (`blocked`) או שיש דריסה מתועדת (`consistencyOverrides`).
5. הורמונים חיצוניים פעילים רק כשהמקור החיצוני מוצג ומוגדר.

כך מי שמוסיף מחלה מקבל התראה מיידית אם הרמות שהגדיר סותרות את מנגנון הציר.

## מבנה הקוד

```
index.html
css/style.css
js/
  core.js            רישום צירים ומחלות, חישוב מצב מצטבר לכל שלב
  illustrations.js   איורי האיברים (SVG) ונקודות חיבור
  scene.js           בניית התרשים: איברים, צינורות, קשתות משוב, שבבי רמה
  simulator.js       מנוע האנימציה: רמות, חלקיקים, ציר זמן
  app.js             ממשק: בית, בחירת ציר, מצב למידה/אבחון
  data/axes/         הגדרת כל ציר: איברים, הורמונים, זרימות, משוב
  data/diseases/     הגדרת מחלות לכל ציר (נתונים בלבד)
tests/validate.js    בדיקת עקביות

```

המנוע אינו מכיר מחלות. הוא מפרש את הנתונים, כך שלכל המחלות אותה לוגיקה.

## הוספת מחלה

מוסיפים אובייקט לקובץ `js/data/diseases/<axis>.js`:

```js
{
  id: 'my-disease',
  nameHe: 'שם בעברית',
  type: 'primary-hypo',            // normal | primary-hyper | secondary-hyper | primary-hypo | secondary-hypo | tertiary-hypo | ectopic | exogenous
  disturbance: { source: 'thyroid', affected: '...', kind: '...' },
  external: { shape: 'lungTumor', labelHe: '...' },   // רק אם יש מקור מחוץ לציר
  directEffects: ['...'], feedbackConsequences: ['...'],
  final: { trh: 'high', tsh: 'high', t3t4: 'low' },   // כל ההורמונים של הציר
  forwardOverrides: { t3t4: 'impaired' },             // autonomous | impaired
  steps: [
    { phase: 'disturbance', dur: 6, title: '...', text: '...',
      highlight: ['thyroid'], status: { thyroid: 'destroyed' }, levels: { t3t4: 'low' } },
    // ... phase: disturbance | response | final
  ],
  explanation: { mechanism: '...', feedback: '...', note: '...' },
}
```

בשלב אפשר להגדיר: `levels` (low/normal/high), `status` (adenoma / hyper / atrophy / destroyed), `highlight`, `show: ['external']`, `blocked: ['fb_pit']` (קשת משוב שאינה פועלת). שלב הפתיחה התקין מתווסף אוטומטית מהגדרת הציר.

## הוספת ציר

1. קובץ `js/data/axes/<id>.js` שקורא ל-`ENDO.registerAxis({...})`: איברים (`nodes`), הורמונים (`hormones`), זרימות (`flows`), קשתות משוב (`feedback`) ושלב פתיחה (`introStep`).
2. קובץ `js/data/diseases/<id>.js` שקורא ל-`ENDO.registerDiseases('<id>', [...])`.
3. שתי שורות `<script>` ב-`index.html`.

כרטיס הציר במסך הבית, מצב הלמידה ומצב האבחון נבנים אוטומטית. צורת חלקיק חדשה מוסיפים כ-`<symbol>` ב-`index.html`, ואיור איבר חדש ב-`js/illustrations.js`.

### שפה חזותית אחידה

| תפקיד ההורמון | צורת חלקיק |
|---|---|
| משחרר (TRH, CRH, GHRH) | עיגול |
| טרופי (TSH, ACTH, GH) | מעוין |
| סופי (T3/T4, קורטיזול) | משולש |
| מעכב (סומטוסטטין) | ריבוע |
| מתווך (IGF-1) | משושה |
| ממקור חיצוני | צורה ייחודית עם קו מתאר: נוגדן (Y), כמוסה, מעוין עם מסגרת לבנה |

קשת משוב: אדום מקווקו עם קצה T = עיכוב, ירוק עם חץ = גירוי, אפור עם X = משוב שאינו פועל.

## החלטות עיצוב שכדאי להכיר

- **המודל איכותי.** שלוש רמות (נמוך/תקין/גבוה). הרמות משפיעות על תדירות החלקיקים ועל שבבי הרמה, ללא ריכוזים מספריים.
- **מצב אבחון לא חושף:** אין שם מחלה, אין סימון מקור, אין שינוי מבני באיברים (גידול, התכווצות), המקור החיצוני מוצג כ"מקור חיצוני לציר" בצורה ניטרלית, והכיתובים כלליים. החלקיקים החיצוניים (נוגדנים, ACTH חיצוני, תרופה) כן מוצגים, כנדרש באפיון. ההסבר מופיע רק אחרי שליחת תשובה.
- **אותן הגדרות בשני המצבים:** מצב אבחון וחשיפת התשובה משתמשים באותו אובייקט מחלה.
- **"איבר פגוע לא מגיב למשוב":** כשאיבר נפגע (למשל יותרת המוח בהיפופיטואיטריזם), קשת המשוב אליו מסומנת ב-X.

## אימות מול ספר הלימוד

הנתונים נבדקו מול "ספר מגמה אנדוקרינולוגיה מקוצר" (פרקי הורמון הגדילה, בלוטת התריס והאדרנל). ההתאמות שנעשו בעקבות הבדיקה:

| נושא | ממצא בספר | מה שונה |
|---|---|---|
| ציר הגדילה: משוב | IGF-1 מעכב את GHRH ואת הפרשת ה-GH. הספר לא מציג עירור של סומטוסטטין על ידי IGF-1 | הוסר עירור הסומטוסטטין. הסומטוסטטין נשאר "תקין" בכל המצבים |
| ציר הגדילה: מחלות | ענקות/אקרומגליה, חוסר ב-GH (יותרת המוח או היפותלמוס) ותסמונת לרון | נוספה תסמונת לרון (GH גבוה, IGF-1 נמוך, עמידות בקולטן). ענקות ואקרומגליה אוחדו כי הרמות זהות, וההבדל נמצא בהסבר (לוחיות גדילה) |
| התריס: סיווג | ראשוני, שניוני ושלישוני, עם השימוטו כדוגמה לראשוני | נוספה תת-פעילות שלישונית (TRH, TSH ו-T3/T4 נמוכים). הראשונית כוללת את ההסבר על השימוטו ומחסור ביוד |
| התריס: אדנומה בהיפופיזה | TSH "גבוה או תקין שאינו תואם" | הנוסח עודכן |
| התריס: שניונית | TSH נמוך/תקין שאינו תואם, TRH גבוה או תקין | הנוסח עודכן |
| קושינג | האדנומה ההיפופיזרית שומרת על רגישות חלקית למשוב | הנוסח שונה מ"עמידה למשוב" ל"מגיבה חלקית". קשת המשוב עדיין מסומנת כלא מספיקה |
| ACTH אקטופי | גידול בריאה או בלבלב | נוסף הלבלב |
| אדיסון ואי-ספיקה משנית | באדיסון נפגע גם האלדוסטרון והעור מכהה. במשנית האלדוסטרון תקין ואין הכהיה | נוסף בהסברים. האלדוסטרון עצמו אינו מודל בציר |

הדברים שאומתו ללא שינוי: ציר TRH-TSH-T3/T4 והמשוב, ציר CRH-ACTH-קורטיזול והמשוב, ציר GHRH/סומטוסטטין-GH-IGF-1, הנוגדנים בגרייבס (נוגדנים מתאי B שמחקים TSH), אדנומה אדרנלית עם ניוון האדרנל הנגדי, מתן סטרואידים חיצוני עם דיכוי ACTH וניוון הבלוטות, והרמות בכל המחלות שהוגדרו.

**מה שבספר ואינו במודל (בכוונה):**
- דלקת הרסנית בבלוטה ויתר-פעילות מושרית יוד: הרמות זהות לאדנומה רעילה, ולכן לא ניתן להבחין ביניהן במצב אבחון. ההבדל בספר נמצא בבדיקת קליטת יוד, שאינה מודל כאן.
- טיפול יאטרוגני בתירוקסין: צריך מקור חיצוני נוסף בציר התריס. אפשר להוסיף לפי הדגם של הגלוקוקורטיקואידים בציר הקורטיזול.
- משוב קצר של GH על עצמו (מוזכר בספר): לא מודל, כי הוא סותר את הסבר הספר ללרון (GH גבוה ללא עיכוב).
- אלדוסטרון, קטכולאמינים, קלציטונין, T4 מול T3 ואבחון, טיפול וסיבוכים.
